# Review reusable agent skills

Use when creating or reviewing `SKILL.md` files. Require one clear purpose, triggers, concise steps, relevant file paths, and verifiable outputs. Eliminate duplicated policy, unsupported promises, inaccessible references, and prompts that force unnecessary reading or tool calls. Test routes and examples before packaging.

Follow root `SKILL.md`. Find external references only when necessary with `python tools/lookup.py find "topic"`.
