# Coding assistants and multi-agent workflows

Use for coding-agent setup, task routing, and orchestration. Prefer one capable agent; use multiple agents only for independent subtasks with a clear benefit. Keep tool permissions and secret access narrow. Select an external tool only after checking its purpose, compatibility, and current documentation. Stop loops that repeat without new evidence.

Follow root `SKILL.md`. Find external references only when necessary with `python tools/lookup.py find "topic"`.
