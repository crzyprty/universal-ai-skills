# Automatic Routing

1. Inspect current tools, project files, and available MCPs.
2. Use an already-connected tool first.
3. If a resource is needed, run `python tools/lookup.py "task"`; without Python, open `BY_NEED.md`.
4. Choose one relevant link or skill. Prefer official docs and direct tools over directories.
5. Fetch only the missing documentation needed to act.
6. Execute and verify; do not ask the user to pick a tool.
7. If login, OAuth, billing, or admin approval is required, prepare the exact next step and request only that required action.

Do not load the whole catalog by default. External resources are not installed merely because their URLs appear here.
