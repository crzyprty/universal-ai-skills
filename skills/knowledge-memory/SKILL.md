# Long-term agent memory

Use for Obsidian, recalled project facts, durable notes, and memory retrieval. Keep a small index, actionable decisions, and links to source material. Store only non-sensitive information the user authorizes. Read the most relevant note first; avoid copying entire chat histories into every context window.

Follow root `SKILL.md`. Find external references only when necessary with `python tools/lookup.py find "topic"`.
