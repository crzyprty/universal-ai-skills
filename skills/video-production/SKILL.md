# Video and speech tools

Use for transcription, video composition, Remotion, and local speech models. Choose a tool based on input/output format and licensing. For video analysis, use frames, captions, or an actual supported video-processing tool rather than pretending a URL was watched. Verify audio/video exports when possible.

Follow root `SKILL.md`. Find external references only when necessary with `python tools/lookup.py find "topic"`.
