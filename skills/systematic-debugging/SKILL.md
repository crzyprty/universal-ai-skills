# Systematic Debugging

1. Capture the exact error and the command/context that produced it.
2. Reproduce the failure when practical.
3. Trace the error to the root cause; inspect relevant logs and dependencies.
4. Make one focused fix, then rerun the smallest relevant check.
5. If the same path fails twice, change the hypothesis or inspect the environment before retrying.
6. Report verified results, not guesses.
