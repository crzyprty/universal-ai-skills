# Test-Driven Development

1. Write a test that expresses the required behavior when practical.
2. Run it and confirm it fails for the expected reason.
3. Implement the smallest change that makes it pass.
4. Run the focused test, then relevant regression checks.
5. Skip ceremony for trivial edits, config-only changes, and disposable prototypes.
