# Fast Execution

1. Infer a reasonable default and begin; do not ask the user to choose tools.
2. Inspect only the relevant workspace and connected capabilities.
3. Use the shortest reliable tool path and filter output.
4. Reuse results; avoid repeated searches and unchanged retries.
5. Verify the outcome and stop.
