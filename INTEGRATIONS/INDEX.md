|---|---|

| Meta Ads campaigns and reporting | [Meta Marketing API](https://developers.facebook.com/docs/marketing-api/) |
| Miro boards and diagrams | [Miro MCP docs](https://developers.miro.com/docs/miro-mcp) |
| n8n workflow automation | [n8n docs](https://docs.n8n.io/) |
| Canva assets and editable designs | [Canva MCP info](https://community.canva.dev/t/the-wait-list-is-over-canva-mcp-server-is-now-generally-available/8942) |
| Current library documentation | [Context7](https://github.com/upstash/context7) |
| Google Analytics data | [Google Analytics MCP](https://developers.google.com/analytics/devguides/MCP) |
| Stripe products, payments, and billing | [Stripe MCP docs](https://docs.stripe.com/mcp) |
| Browser tests | [Playwright CLI](https://github.com/microsoft/playwright-cli) |
| CRM and marketing | [HubSpot developers](https://developers.hubspot.com/) |
| Notion workspace | [Notion MCP docs](https://www.notion.com/help/notion-mcp) |
| Cross-app automation | [Zapier MCP docs](https://help.zapier.com/hc/en-us/articles/48308034391821-What-is-Zapier-MCP) |
| GitHub repositories and issues | [GitHub MCP](https://github.com/github/github-mcp-server) |
| Shopify development | [Shopify Dev MCP](https://shopify.dev/docs/apps/build/devmcp) |
| Figma design context | [Figma MCP docs](https://developers.figma.com/docs/figma-mcp-server/) |
| Vercel deployments | [Vercel MCP docs](https://vercel.com/docs/ai-tooling/vercel-mcp) |
| Chrome console, network, performance | [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp) |

The agent should choose the route based on the task and connected capabilities; the user should not have to select a tool.
