This is a quick routing sheet, not a copy of the upstream projects. Follow the linked upstream documentation for exact installation and current capabilities.

## How to apply them

- Do not blindly install every project. Use the behavior or tool that matches the current task.
- When a project-specific runtime or plugin is needed, follow its current official setup guide.
- Keep this bundle lightweight: upstream projects are linked, not vendored or preinstalled.
