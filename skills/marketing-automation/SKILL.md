# Marketing and Automation

1. Select the relevant connected account tool first.
2. For Meta Ads use the Marketing API docs; for Google Analytics use the read-only Analytics MCP; for CRM use HubSpot; for ecommerce use Shopify.
3. Use n8n for workflow orchestration and Zapier MCP for cross-app actions when available.
4. Fetch current official docs for fields, scopes, and limits.
5. Preview the planned write/action where supported; verify the returned state after execution.
